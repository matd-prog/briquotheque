Outils

📚 Catalogue BrickLink (recherche par nom)

  1. Connectez-vous sur BrickLink, puis ouvrez la page de téléchargement du catalogue.
  2. Choisissez Catalog Items, Minifigures, Tab-Delimited File (cochez Year Released si proposé), puis Download.
  3. Touchez le bouton ci-dessous et choisissez le fichier téléchargé (Minifigures.txt, parfois nommé Minifigures.txt.xml).

Refaire d'un coup les étiquettes (QR code) de toutes les figurines déjà présentes dans le fichier.

Encadrez la figurine : glissez le cadre, ou tirez ses coins.

🎨 Figurine custom (JB Spielwaren ou autre fabricant) : elle sera rangée dans l'onglet « Customs ».

Sur la page de la figurine : ⋮ → Partager → Copier le lien, puis collez-le ici. Le QR code de l'étiquette ouvrira cette page. Sans lien, l'étiquette n'aura pas de QR code.

Ajouter à ma collection ?

📚 Base commune des blisters JB : photographiez vos blisters un par un. Le nom est lu tout seul : vérifiez-le, puis « Ajouter à la base ». Quand vous avez fini, « Exporter » crée un fichier à m'envoyer : ces blisters seront ensuite reconnus par l'appli (nom et décor).

Le fichier va dans « Téléchargements » : envoyez-le moi (ou mettez-le dans Google Drive). Les blisters restent dans le téléphone tant que vous ne les effacez pas.

Autre méthode : télécharger, puis importer dans Google Drive ⬇️ 1. Télécharger le fichier

2. Le mettre dans Google Drive

  1. Ouvrez l'appli Google Drive.
  2. Touchez le bouton + (en bas à droite), puis Importer.
  3. Choisissez Téléchargements, puis le fichier dont le nom est affiché ci-dessus.

Votre ancien fichier n'est pas effacé : le nouveau porte la date et l'heure dans son nom.
