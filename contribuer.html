📚 Blisters JB

Base commune des blisters JB Spielwaren
📲 Sur iPhone, installez d'abord l'appli : touchez Partager (le carré avec une flèche ⬆️, en bas de Safari), puis « Sur l'écran d'accueil », puis Ajouter. Ouvrez ensuite « Blisters JB » depuis l'écran d'accueil. Sinon, Safari peut effacer vos blisters après quelques jours sans utilisation.

⚠️ Vous avez déjà blister(s) ici. L'appli installée ne les verra pas : touchez d'abord « 📤 Envoyer les blisters » puis « Enregistrer dans Fichiers ». Dans l'appli installée, touchez ensuite « 📥 Reprendre des blisters déjà photographiés ».

Photographiez vos blisters JB Spielwaren un par un, de face. Le nom est lu tout seul : vérifiez-le : l'appli vous dit s'il est déjà connu et si vous l'avez déjà photographié. Notez le numéro écrit à la main, puis « Ajouter ». Quand vous avez fini, touchez « Envoyer » et envoyez le fichier à Mathias (Messages, WhatsApp, Mail…). Merci !

📌 Cadre mémorisé : les photos sont recadrées comme la première de la série.

Ajustez le cadre autour du blister : glissez-le, ou tirez ses coins.

📷 Maintenant le verso : retournez le blister (le nom se lit pendant ce temps).

Le blister rejoint aussi la base commune de reconnaissance (s'il n'y est pas déjà).

Le fichier va dans « Téléchargements » : envoyez-le moi (ou mettez-le dans Google Drive). Les blisters restent dans le téléphone tant que vous ne les effacez pas.
